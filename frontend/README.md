# StellarStake Frontend

This is the React frontend application for the Soroban Staking Reward Platform.

## Features

- **Wallet Integration**: Support for Freighter and Albedo wallets via `@creit.tech/stellar-wallets-kit`.
- **Staking Management**: Stake XLM tokens, view pending RWT rewards accrued in real-time, and claim rewards.
- **Event Logs**: Live activity feed of network events (`Staked`, `Unstaked`, `Claimed`).

## Getting Started

### Installation

```bash
npm install
```

### Running the Application

To run the dev server locally:

```bash
npm run dev
```

### Run Tests

To run the Vitest test suite:

```bash
npm run test
```

### Linting

To run the Oxlint linter:

```bash
npm run lint
```
